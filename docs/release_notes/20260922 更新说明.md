20260922 更新说明（20260921 至 20260922）

更新重点：
- FP8 DeepSeek MLA KV cache 默认布局由逐 token `[512B FP8,16B scales,128B RoPE]` 改为逐页 `[B,640B payload]` 后接 `[B,16B scales]`，保持 `uint8 [P,B,656]` 容量视图不变，使每个 token 的 FP8 latent 与 RoPE payload 均按 128B 对齐。`reshape_and_cache_mla_fp8_ds`、`fused_mla_rope_cache`、`unified_attention_mla_fp8_ds` 和 `sparse_mla_fp8` 的 writer/reader 已统一使用编译期布局。
	- 这是不兼容的 cache 字节 ABI 变更：旧 cache、离线测试数据及 cache transfer 数据必须重新生成或显式转换；修改布局开关后必须重编 `torch_xcpu` 并重启服务。
- MCPU Inductor C++ wrapper 生成的设备 kernel 现在通过 `MCPU_LAUNCH_TIMED_KERNEL` 投递，并为原始指针建立 `KernelPointerMemoryGuard`；同时补齐调度器的 `fuse` 委托，避免不同迭代维度融合后在 codegen 阶段失配。

备注：
- vLLM 与 `torch_mpi_ext` 本次无代码更新；按要求不生成 vLLM 整仓库源码包。

## `torch_xcpu` 算子变更

	- commit `e591428567cebe60624e065f6c7dd4fe5a11af19`：[MLA] support new kv-cache layout [B,640]+[B,16] scales for 128B align access, replace old layout [512B FP8,16B scales,128B RoPE]

	- commit `e591428567cebe60624e065f6c7dd4fe5a11af19`：[MLA] support new kv-cache layout [B,640]+[B,16] scales for 128B align access, replace old layout [512B FP8,16B scales,128B RoPE]
	- 测试：`torch_xcpu/test/ops/custom_ops/test_unified_attention_fp8_mla.py`、`torch_xcpu/test/ops/custom_ops/test_sparse_mla_fp8.py`
