20260921 更新说明（20260917 至 20260921）

更新重点：
- 新增 DeepSeek V4 mHC 系列算子，覆盖首层 residual broadcast、pre、post、相邻层 post-pre 融合及最终 head collapse；针对 4096/5120 hidden size 提供离线调优的 baseline、tiled、AVX512/AMX 实现和固定路由。
	- 特别关注：请算子同学特别关注基于 tunning 的调优范式如 `torch_xcpu/torch_xcpu_impl/include/deepseek_v4/mhc_fused_post_pre_avx512_and_amx.inc`
- 为 Qwen3.8-27B DFlash2 / GLM5.2 新增 `aten::add.Tensor`、`aten::mul.Tensor`、`aten::fill_.Scalar`、`aten::index.Tensor` 和 `aten::topk.values` 的 XCPU 专用路径
- DFlash2 eager V2 路径可预分配 packed aux residual buffer，由 Gemma RMSNorm 将各层 residual 直接写入目标 slot，避免逐层 `aten.add` 和最终 `aten.cat`
- 修复 GLM-5/DeepSeek sequence-parallel 布局判定：短 token 数场景不再只依赖 tensor 首维推断布局，并在普通、Eagle/MTP、LongCat 和 Qwen3.5/Next 路径显式跟踪布局。
- 异步执行路径改为仅捕获受内存保护的原始指针和必要元数据，覆盖 torch_mcpu binary out、XCPU index/TopK/MoE prepare/MPI gather 以及 torch_mpi_ext collectives，避免队列任务持有 Tensor owner 导致显存延迟释放，修复 GLM5.2 使用 moe_alltoallv_v6 时存在每层增加 108MB 然后每个 step 释放一次造成过高峰值内存占用的情况。
- AFD V7 支持 Attention ranks 与 Expert ranks 不相同的拓扑，并补充 bootstrap、client、session、MPI world 和多拓扑 round-trip 测试。
	- 请 AFD 测试人员注意，本仓库新增专用 `serve_afd_mp_rpc_all_mpi_template.sh`，按 `A=DP×TP×PP`、`F=EP` 划分同一 MPI world，更新跨节点矩阵以覆盖 A4/F2、A1/F4、A4/F1、A2/F2 及 BF16/FP8/MXFP4A16，并补充作业管理系统接入说明和 hostfile 测试。

## `torch_xcpu` 算子变更

- `add_4d_lastdim_impl`（新增 ATen 专用实现）：接管 `aten::add.Tensor` 的 XCPU 路径，将 1 至 4 维输入归一化为 4 维执行；支持 BF16/FP32 同 dtype 或混合 dtype、非负 outer stride 和广播，要求最后一维连续或广播、128-byte 对齐、总元素数至少 1024、最后一维为 16 的倍数且 `alpha=1`，其余输入回退到原 host kernel。
