## torch_xcpu 算子变更

范围：2026-11-18 发布快照 `eada8266e344906c099e18126e918bc80080d624`（共同祖先 `28da327f63e0827384beb1a7fc5e2fa793cc5ab6`，不含；排除 rebase 重放 `7a7606e61c845f8e5fbe303f56a5998fa5b9880b`）至 `f42b8762a9da87d3c20c94c4b0f8b09c70481efa`（含），共 5 个新增提交，全部为 `dev/0.31` 第一父链提交。

测试用于佐证行为，不代表覆盖了全部 shape、dtype、后端和并行组合。本次打包没有重新运行算子测试，结论取自各提交 diff 与源码契约。
