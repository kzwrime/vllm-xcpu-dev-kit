20260621 更新说明（20260615 至 20260621）

更新重点：
- 大幅度减少 Qwen3.5/3.6 系列模型在新版 torch_mcpu stream 模式下的 Torch Peak Memory，修复上一版本异常升高的问题，Qwen3.5-0.8B TP2 MAX_NUM_BATCHED_TOKENS=6144 时，从 5.5GB 左右下降到 0.2GB 左右。
- 优化了逻辑上 H2D/D2H/D2D 的性能
- 改善部分算子的捕获 Tensor 后释放带来的生命周期延长问题和尾空泡问题
- 小幅度改善了 Qwen3.5/3.6 Prefill 的性能，消除了 2 处 copy。
- 小幅度改善了 Qwen3.6-35B-A3B 的性能，消除了 1 处 arange
- 支持 MTP
- 修复了 PD 分离 example connector 时 Chunk Prefill 会多次存储文件的问题。

备注：
- causal_conv1d_fn 发生了扩展性变更！注意算子跟进！
- index_select_dim0 发生了扩展性变更！注意算子跟进！
- torch_mpi_ext 的 all_reduce 的 bf16 over fp32 版实现发生小变化，注意代码合并时解决冲突。
- MTP
	- 试验了 MTP 预测 1/2 个 Token 的情况，Qwen3.5-0.8B 上效果存在问题，但 Qwen3.5-4B 及以上模型可用性好
	- MTP 性能依赖于短 Chunk Prefill，目前尚未得到良好优化
	- 配合 chunk_gated_delta_rule 的改造仍有进一步消除 Prefill 阶段该算子前后的 copy/index 算子的机会
