# 20261008 更新说明（20261006 至 20261008）

## 更新重点

- 修复 GDN 混合 prefill/speculative decode 时门控 a/b 与 QKV token 索引错位；vLLM Python 路径与 torch_xcpu 融合路径同步修复，插件补充回归与来源审计。
- 矩阵乘支持 BF16/FP16 输入直接保留 FP32 累加输出，插件 XcpuGateLinear 接入无 bias 的 FP32 router logits 路径。
- 新增二维常量 padding，vLLM sequence parallel padding 在符合输入契约时调用 torch_xcpu；已对齐输入直接返回原张量。
- torch_mpi_ext 新增非原地 all_reduce_out 及 wrapper，插件 all_reduce 返回独立输出，便于 torch.compile 规划内存且保留输入。
- MoE v5/v6/v7 共用 hybrid pack/reduce，按批量切换发送布局并缩小发送缓冲区；新增 AF v8 双边 MPI_Alltoallv dispatch/combine 与插件接入。

请实验 AFD V8。

## torch_xcpu 算子变更

统计范围为上一版基线 `dd4d3781f6ae78903503c5c08cc10fb097ccc6fd`（不含，2026-10-06）至 `140068877879cc8afa2e22aad65ce1e41c15f067`（含，本次 2026-10-08 发布快照）。部分后继提交的作者日期仍为 2026-10-06，范围按 Git 提交拓扑确定，不按作者日期筛选。本次未另行指定交付后区间或排除模块，以下记录该基线之后的实际兼容性变化。测试用于佐证行为，但不代表覆盖全部 shape、dtype、后端和并行组合；本次文档打包未重新运行算子或端到端测试。

- `qwen_gdn_attention_core`（小修改）：混合 speculative 与非 speculative token 时，a/b 与 mixed_qkv 使用同一 spec_token_indices 在第 0 维 gather，再进入 recurrent update。修复 prefill 排在 speculative decode 前面时错误读取前部 gates、污染输出及 SSM 状态的问题。纯 speculative batch 继续复用原视图，schema 和从核参数结构未变；替换融合实现的 NPU 路径也必须同步索引。
