## `torch_xcpu` 算子变更

统计范围为 2026-08-26（不含）至 `57c3a286f823b83684e18a68723dd44c70ecad3b`（含）。以下测试用于佐证所述行为，不代表覆盖全部 shape、dtype、后端和并行组合。

- `einsum_mhk_hkn_to_mhn`（大修改）：A0 从逐元素四重循环改为按 M/N/K 分块、FP32 累加和 OpenMP 并行的模型专用实现，并把实现族/版本分发移到 C++ bridge；输入契约现明确要求 H 为 8 的正倍数、K 为 64 的正倍数、N 为 32 的正倍数，K 维连续且 input head stride 为 64 的倍数，weight/output 连续，仅支持 FP32/BF16。同一算子的优化团队 B0 路径保留。
	- commit `c69169d674bbd23c928e91d9de702d98de94d254`：[Einsum] update einsum_mhk_hkn_to_mhn
	- 测试：`torch_xcpu/test/ops/custom_ops/test_einsum_mhk_hkn_to_mhn.py`
- `einsum_blpr_blcr_to_blpc`（新增算子）：新增显式 out 算子，计算 `[B,L,P,R] x [B,L,C,R] -> [B,L,P,C]`，使用 FP32 累加和 OpenMP 并行；输入、权重和输出须同 dtype/设备，支持 FP32/BF16，并要求各 tensor 最后一维连续。
	- commit `2275c9d009ad43784ea09a5e60e2a61e403435b4`：[SpecDecode] Support DFlash2: update & add ops (#38)
	- 测试：`torch_xcpu/test/ops/custom_ops/test_einsum_blpr_blcr_to_blpc.py`
- `dflash2_grouped_conv`（新增算子）：新增显式 out 的 DFlash2 causal grouped convolution，将 base/delta coefficient 与多 tap 累加融合，并按 `token % block_size` 截断跨 request block 的历史访问；支持 FP32/BF16、FP32 累加，要求 group 数整除 hidden size 且各 tensor 最后一维连续。
	- commit `2275c9d009ad43784ea09a5e60e2a61e403435b4`：[SpecDecode] Support DFlash2: update & add ops (#38)
	- 测试：`torch_xcpu/test/ops/custom_ops/test_dflash2_grouped_conv.py`
- `gumbel_sample`（中等修改）：底层 Torch schema 和 Python 包装将可选输出重命名为 `logits_cache` / `logits_cache_col`；cache 从 temperature 处理后的 FP32 logits 改为处理前、与输入 logits 同 dtype 的原始值，逻辑形状固定为 3D，并新增独立的 request/step stride。旧关键字和旧 FP32 processed-logits 语义不兼容。
	- commit `2275c9d009ad43784ea09a5e60e2a61e403435b4`：[SpecDecode] Support DFlash2: update & add ops (#38)
	- 测试：`torch_xcpu/test/ops/custom_ops/test_gumbel_sample.py`
- `vllm_rejection_compute_local_logits_stats`（中等修改）：draft cache 改按 raw logits 读取并在 max/sumexp 计算中除以 request temperature；target 与 draft logits 改为独立 dtype dispatch，支持 FP32、FP16、BF16 任意组合，同时保留 FP32 统计输出和 draft cache 最后一维连续要求。
	- commit `2275c9d009ad43784ea09a5e60e2a61e403435b4`：[SpecDecode] Support DFlash2: update & add ops (#38)
	- 测试：`torch_xcpu/test/ops/custom_ops/test_rejection_sampler.py`
- `vllm_rejection_resample`（中等修改）：resample 的 residual probability 改为对 raw draft logits 显式应用 request temperature，并将 target/draft dtype 分离 dispatch，支持 FP32、FP16、BF16 的不同组合；Torch schema 参数顺序未变。
	- commit `2275c9d009ad43784ea09a5e60e2a61e403435b4`：[SpecDecode] Support DFlash2: update & add ops (#38)
	- 测试：`torch_xcpu/test/ops/custom_ops/test_rejection_sampler.py`
- `sparse_indexer`（小修改）：prefill/decode top-k 内部不再依赖 `c10::Float8_e4m3fn` 标量转换，改为按 4 个元素使用 portable FP8 E4M3FN 精确 LUT 解码，并保留不足 4 元素的 tail 处理；接口、shape 和 dtype 契约不变。
	- commit `ac1df546f56ddd79b71726d4ff3e6c40efa7ac1e`：[Indexer] use portable_fp8_conversion in sparse_indexer
	- 测试：`torch_xcpu/test/ops/custom_ops/test_sparse_indexer.py`
