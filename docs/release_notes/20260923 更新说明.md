20260923 更新说明（20260922 至 20260923）

更新重点：
- GLM5.2 支持 torch.compile，目前存在 2 处 python 回调。--bench 测试时，建议在第二轮才开始记录 profiler。
- 新增水平融合算子接口 `fused_mla_rope_qproj_cat_cache`，能消除部分 aten 算子，并且为后续水平融合奠定基础，目前实现为依次顺序调用。
- `fused_add_rms_norm` 增强了 Strided Input Tensor 支持，用于配合 vLLM 的 torch.compile 优化
- FP8 MLA cache 的原生入口补齐布局与 4B 对齐检查，`sparse_mla_fp8` 在原生层核验 CPU metadata header 与当前 query/backend 的维度，避免动态 token 数被 Python 计数固定在编译图中。


## `torch_xcpu` 算子变更

统计范围为上一版基线 `e591428567cebe60624e065f6c7dd4fe5a11af19`（不含）至 `4580a65dfafa6b5b6eb5e1289a1445e405f3375d`（含，终点提交日期 2026-09-23）。以下测试用于佐证所述行为，不代表覆盖全部 shape、dtype、后端和并行组合。

- `fused_mla_rope_qproj_cat_cache`（新增算子）：接收 BF16 `q [T,H,K+64]`、连续 `w_uk_t [H,K,512]`、`k_pe [T,64]`、`kv_c [T,512]`，原地更新 `k_pe`/KV cache，并写入 `out_q [T,H,576]`。`K` 为正的 64 倍数，`slots` 长度可小于 `T`；负 slot 或无 slot 的行仍投影 Q_nope、复制未旋转 Q_pe，且不改动 K/cache。支持 BF16 `[P,B,576]` 或新版 FP8 `uint8 [P,B,656]` cache，写入目标不得与输入或其他输出重叠。A0 当前是同一 dispatcher 操作内的两次有序 kernel launch；B0 尚未实现。新增 Torch schema 与底层参数结构，NPU 实现及 AOTI wrapper 需要按新接口接入。
	- commit `8c8e098ec4f3f1157a08b846ed1cc469b065ba9d`：[MLA][Fusion] combine fused_mla_rope_cache_kernel and einsum_mhk_hkn_to_mhn_cpu_impl to fused_mla_rope_qproj_cat_cache to avoid extra aten::cat (#41)
	- 测试：`torch_xcpu/test/deepseek_v32/test_fused_mla_rope_qproj_cat_cache.py`、`torch_xcpu/test/deepseek_v32/test_sparse_mla_compile_contract.py`
- `einsum_mhk_hkn_to_mhn`（小修改）：底层参数新增输出 token/head stride，允许将 Q up-projection 直接写入更宽的 `[T,H,576]` 查询缓冲区前 512 列；独立 Torch 调用仍写入连续 `[T,H,512]` 输出。绑定与 `torch_xcpu_impl` 的参数结构 ABI 已改变，须配套重编。
	- commit `8c8e098ec4f3f1157a08b846ed1cc469b065ba9d`：[MLA][Fusion] combine fused_mla_rope_cache_kernel and einsum_mhk_hkn_to_mhn_cpu_impl to fused_mla_rope_qproj_cat_cache to avoid extra aten::cat (#41)
	- 测试：`torch_xcpu/test/deepseek_v32/test_fused_mla_rope_qproj_cat_cache.py`
- `fused_mla_rope_cache`（小修改）：底层 RoPE/cache kernel 支持 Q 输入与输出使用不同指针和行 stride，以供新融合算子直接写入最终查询；原有 Torch schema 和原位调用保持不变。FP8 写入的原生入口现在校验 `uint8 [P,B,656]`、token stride 656、仅页间 padding 与 4B 页对齐，即使 Python 检查关闭也会执行。
	- commit `8c8e098ec4f3f1157a08b846ed1cc469b065ba9d`：[MLA][Fusion] combine fused_mla_rope_cache_kernel and einsum_mhk_hkn_to_mhn_cpu_impl to fused_mla_rope_qproj_cat_cache to avoid extra aten::cat (#41)
	- 测试：`torch_xcpu/test/deepseek_v32/test_fused_mla_rope_qproj_cat_cache.py`
- `sparse_mla_fp8`（小修改）：原生 reader 校验 FP8 cache 布局、4B 页对齐和连续 CPU `int32[16]` metadata header，并在运行时核对 query 数、head 数、request 数及 `bn`；编译期间不再用 Python metadata 计数约束动态 query 维度。Torch schema 不变。
	- commit `8c8e098ec4f3f1157a08b846ed1cc469b065ba9d`：[MLA][Fusion] combine fused_mla_rope_cache_kernel and einsum_mhk_hkn_to_mhn_cpu_impl to fused_mla_rope_qproj_cat_cache to avoid extra aten::cat (#41)
	- 测试：`torch_xcpu/test/deepseek_v32/test_sparse_mla_compile_contract.py`
- `fused_add_rms_norm`（小修改）：in-place 与 out 变体的 input、residual、output、residual_out 分别使用独立行 stride，支持 1D 或最后一维连续且行不重叠的 2D 张量，包括非零 storage offset 的 split 视图；仍要求连续 `[H]` weight、匹配 shape/dtype/device，拒绝转置等最后一维非连续布局。Torch schema 不变，底层参数结构新增三个 stride 字段。
	- commit `4580a65dfafa6b5b6eb5e1289a1445e405f3375d`：[CustomOps] update fused_add_rms_norm to support strided inputs
	- 测试：`torch_xcpu/test/ops/custom_ops/test_fused_add_rms_norm.py`
