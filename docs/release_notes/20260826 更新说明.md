20260826 更新说明（20260825 至 20260826）

更新重点：
- 融合 Qwen3.5/Qwen3.6 GDN 的 QKV、Z、B、A 输入投影；`torch_xcpu` 新增 packed QKVZBA 组合算子，在算子内以元数据 view 拆分投影结果，并将 GDN attention core 与 gated RMSNorm 写入显式输出，减少 dispatcher/AOT 边界上的别名与拷贝。
- 修复多节点 compile cache 因 loopback IP 不同而无法复用、非原生 FP8 平台 MLA `kv_b_proj` 反量化、Mamba block size 校验和 ZMQ 资源释放等问题。
- 预测解码 speculator 在 XCPU 平台使用 `torch_xcpu.ops.argmax_out`。

备注：
- 本次为小幅度更新；`torch_mcpu`、`torch_mpi_ext` 和 `vllm-xcpu-plugin` 无新提交。
