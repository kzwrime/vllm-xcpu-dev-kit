20260909 更新说明（20260901 至 20260909）

更新重点：
- 端到端接入 XCPU 的 DeepSeek V3.2 / GLM-5.2 DSA sparse indexer 加速路径，覆盖 K cache、Q RoPE、prefill/decode logits、调度 metadata、TopK 与 ragged sequence pack/unpack
- 修复 Qwen3Next / Qwen3.5 sequence parallel 层边界，并支持通过 `VLLM_DISABLE_ATTN_REDUCE_SCATTER_FOR_MOE` 关闭 attention reduce-scatter 优化
- 更新 GLM-5.2、Qwen3.6、Qwen3.8/DFlash2 presets、长上下文准确率检查及 SpecBench 测试脚本

备注：
- 注意版本更新后删除 `vllm_cache`，避免命中旧版本生成的 compile cache
- DSA sparse indexer 当前支持 H={32,64}、D=128、TopK={512,1024,2048}、量化块 128；XCPU 加速路径要求 PCP=1、DCP=1，支持 64/128-token cache page
- GLM5.3 使用短问题测试无法触发稀疏注意力 (其原理为 2K 稠密的 local windows + 2K TopK 稀疏)，建议使用长下文测试脚本测试 0.5K, 2K, 4K, 8K
- torch_xcpu 的性能关键算子请参考文档
	- torch_xcpu/docs/deepseek_v32/sparse_indexer.md
		- fp8_fp4_mqa_logits
		- fp8_fp4_paged_mqa_logits
	- torch_xcpu/docs/deepseek_v32/sparse_indexer_topk.md
		- top_k_per_row_prefill
		- top_k_per_row_decode
	- 由于大量时间在进行算子优化设计，时间原因测试简易，请自行补充测试。

## `torch_xcpu` 算子变更

统计范围为 2026-09-01（不含）至 `a7f0e083e6f3122e1b1347bf8e0bd44a6ecc89c5`（含）。以下测试用于佐证所述行为，不代表覆盖全部 shape、dtype、后端和并行组合。

- `sparse_indexer_pack_seq`（新增算子）：新增通用 ragged sequence pack/unpack out 算子，在 `[T,...]` 与 `[B,N,...]` 间按 int32 lengths 搬运任意同 dtype 数据；输出必须连续，decode 用它补齐 BF16 Q/FP32 weights，并将 TopK int32 结果还原为扁平 token 顺序。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_pack.py`
- `indexer_k_quant_and_cache`（新增算子）：新增 BF16 `[T,128]` K 到分页 FP8 cache 的量化写入，按 int64 slot mapping 定位并跳过负数 padding slot；cache 为 uint8 `[P,PAGE_KV,132]`、PAGE_KV 支持 64/128，量化块固定 128，scale 支持 FP32/UE8M0 表示。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_cache.py`
- `cp_gather_indexer_k_quant_cache`（新增算子）：新增按 int32 block table 与 cumulative sequence lengths 从分页 cache gather 的 out 算子，输出连续 FP8 K `[N,128]` 和以 uint8 `[N,4]` 承载的 FP32 scale，支持乱序物理页和 64/128-token page。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_cache.py`
- `fused_indexer_q_rope_quant`（新增算子）：新增 Q RoPE 与 head weight scaling 融合算子；输入 Q 为 BF16 `[T,H,128]`，cos/sin cache 和 weights 支持 BF16/FP32，输出 BF16 rotated Q 与 FP32 weights。支持 H=32/64、GPT-J/Neox RoPE，DeepSeek-V4 tail RoPE 仅支持 GPT-J interleaved。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_fused_q.py`
- `fp8_fp4_mqa_logits`（新增算子）：新增 prefill sparse-indexer logits 算子，计算 BF16 Q、FP8 K/FP32 K scale 与 FP32 head weights 的融合 MQA 分数；支持 H=32/64、D=128 和 ragged int32 key 起止区间，返回带内部对齐 stride 的 FP32 `[M,N]` view，当前仅支持 `clean_logits=False`。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_prefill.py`
- `get_paged_mqa_logits_metadata`（新增算子）：新增 decode 调度 metadata 的 functional/out 接口，按 `[B,next_n]` context lengths、256-token KV 分块和设备 compute-unit 数生成 `[num_sms,capacity+1,2]` 任务表；支持 next_n 1～10，out 变体可复用预分配 buffer 以供图执行。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_decode_metadata.py`
- `fp8_fp4_paged_mqa_logits`（新增算子）：新增 decode/MTP 分页 sparse-indexer logits 算子，直接读取 uint8 `[P,PAGE_KV,1,132]` FP8 K+FP32 scale cache，并消费独立 metadata 任务表；支持 next_n 1～10、H=32/64、D=128、64/128-token page，输出 FP32 `[B*next_n,max_model_len]`，当前仅保证 context length 内有效且仅支持 `clean_logits=False`。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_decode.py`
- `top_k_per_row_prefill`（新增算子）：新增 prefill FP32 logits 的显式 out TopK，按每行 int32 起止区间选择索引，支持 K={512,1024,2048}；实现提供 A0～A6 版本切换，并引入 vendored `x86-simd-sort` 支持 SIMD selection，短行按原始顺序输出并以 -1 补齐。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- commit `a7f0e083e6f3122e1b1347bf8e0bd44a6ecc89c5`：[Deps] add deps/x86-simd-sort
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_topk.py`
- `top_k_per_row_decode`（新增算子）：新增 decode FP32 logits 的显式 out TopK，按连续 int32 lengths 限定每行有效范围，支持 K={512,1024,2048}；与 prefill 共用可切换的串行/协作 selection 实现和 `x86-simd-sort` 依赖，短行以 -1 补齐。
	- commit `e43bd69817be92fea82c750806a2b8ab9c9824cb`：[DSA] optimize DSA by impling cuda-like fused-op
	- commit `a7f0e083e6f3122e1b1347bf8e0bd44a6ecc89c5`：[Deps] add deps/x86-simd-sort
	- 测试：`torch_xcpu/test/deepseek_v32/test_indexer_topk.py`
- `gather_paged_k_bf16`、`indexer_prefill_topk`、`indexer_decode_topk`（移除）
